# ⚡ Quick Start Guide\n\n## 🏃 Démarrer en 5 minutes\n\n### Étape 1: Choisir votre template\n\nSélectionnez votre type de projet:\n\n- **TypeScript/JavaScript** → `ci-typescript.yml`\n- **Python** → `ci-python.yml`\n- **Shell/Docker/Ansible** → `ci-shell-docker.yml`\n- **HTML/Web** → `ci-html-web.yml`\n- **Déploiement Node.js** → `deploy-nodejs.yml`\n\n### Étape 2: Créer le dossier `.github/workflows`\n\n**Via GitHub Web UI:**\n1. Allez sur votre repo\n2. Cliquez `Add file` → `Create new file`\n3. Tapez: `.github/workflows/ci.yml`\n4. Acceptez la création du dossier\n\n**Via Git CLI:**\n```bash\ngit clone https://github.com/Krohler06/your-repo.git\ncd your-repo\nmkdir -p .github/workflows\n```\n\n### Étape 3: Copier le contenu\n\n1. **Ouvrez le template** depuis ce repo\n2. **Cliquez sur Raw** pour voir le contenu brut\n3. **Copiez tout** le contenu YAML\n4. **Collez-le** dans votre fichier `.github/workflows/ci.yml`\n5. **Commitez et pushez**\n\n### Étape 4: Tester\n\n1. **Allez sur votre repo** → **Actions**\n2. **Voyez le workflow** s'exécuter\n3. **Cliquez dessus** pour voir les logs\n\n---\n\n## 🔧 Configuration spéciale par type\n\n### TypeScript/JavaScript\n\n✅ Fonctionnel par défaut si vous avez:\n- `package.json`\n- `package-lock.json` ou `yarn.lock`\n- Scripts npm: `lint`, `build`, `test` (optionnels)\n\n**À personnaliser:**\n```yaml\nnode-version: [18.x, 20.x]  # Votre version Node\n```\n\n### Python\n\n✅ Fonctionnel par défaut si vous avez:\n- `requirements.txt` ou `requirements-dev.txt`\n- Dossier `tests/` avec tests pytest\n\n**À personnaliser:**\n```yaml\npython-version: ['3.9', '3.10', '3.11']  # Votre version Python\n```\n\n### Shell/Docker\n\n✅ Fonctionnel par défaut si vous avez:\n- Fichiers `.sh` dans le repo\n- `docker-compose*.yml`\n- Fichiers `.yml` ou `.yaml` pour Ansible\n\n**À personnaliser:**\nRien! Fonctionne sans configuration\n\n### Déploiement Node.js (elegantly-agencia.com)\n\n⚠️ **À configurer obligatoirement:**\n\n1. **Allez dans Settings → Secrets and variables → Actions**\n2. **Créez ces secrets:**\n\n```\nVERCEL_TOKEN = <votre-token>\n# OU\nNETLIFY_TOKEN = <votre-token>\n# OU\nSSH_USER = votre-user\nSSH_HOST = votre-host\nSSH_KEY = votre-private-key\n```\n\n3. **Modifiez le workflow** pour adapter la commande de déploiement:\n\n```yaml\n# Pour Vercel\nvercel --prod --token ${{ secrets.VERCEL_TOKEN }}\n\n# Pour Netlify\nnetlify deploy --prod --auth ${{ secrets.NETLIFY_TOKEN }} --dir dist\n\n# Pour SSH\nscp -r dist/* ${{ secrets.SSH_USER }}@${{ secrets.SSH_HOST }}:/var/www/html/\n```\n\n---\n\n## 📋 Ordre d'implémentation recommandé\n\n### Jour 1 - Priorité 1 (Immédiat)\n```\n1. elegantly-agencia.com\n   ├─ .github/workflows/ci-typescript.yml\n   └─ .github/workflows/deploy-nodejs.yml\n   \n2.
